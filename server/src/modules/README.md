# 后端业务模块

`router.py` 负责 HTTP 参数和依赖，`schemas.py` 描述接口契约，`models.py` 定义表及约束，`service.py` 执行业务规则并管理写事务。

学习流程由 [question](question/README.md) 组卷、[exam](exam/README.md) 判分和结算，[wrongbook](wrongbook/README.md) 与 [favorite](favorite/README.md) 提供复习入口，[user](user/README.md) 持有身份、资料和学习看板。运营功能分在 [admin](admin/README.md)、[feedback](feedback/README.md) 与 [content](content/README.md)。[ai](ai/README.md) 保留待接回的实现。
