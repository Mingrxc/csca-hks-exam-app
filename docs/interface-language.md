# 中英界面切换

更新日期：2026-10-26。用户已确定本次版本为 1.5.2；双语代码和定稿公告已准备，尚未在本次任务中部署或发布。

## 使用方式

“我的”页面提供始终可见的“语言 / Language”，可选择“简体中文”或“English”，无需先登录。切换后当前界面、原生导航标题和四个原生 TabBar 标签立即更新；缓存页面下次显示时同步标题。

首次使用跟随微信语言：中文语言代码使用简体中文，其他语言使用英语；无法取得语言时使用中文。手动选择以本机 `app_language_v1` 保存，优先于微信语言，不随退出登录清除，也不在服务器同步。

## 翻译范围

- 页面标题、按钮、占位提示、弹窗、加载/空/失败状态及常用错误提示。
- 考试科目、模块、题型、难度、练习方式、常用任务和错因标签。筛选选项只改变显示文本，提交及存储仍用原始值，`HKS` 接口标识保持不变。
- 等级、题数、成绩、自评、倒计时单位等使用整句占位参数，避免英文语序被中文片段拼接限制。
- 题干、选项、答案、解析、听力原文、评分细则和细粒度题库知识点保留原文。品牌名、用户昵称、反馈内容、公告标题/正文及既有聊天记录不自动翻译。
- 新点击的 AI 示例问题跟随当前语言生成；已有输入草稿、题目上下文和消息不会在切换时重写。
- 错题 PDF 的题目及内容继续保持原样，本轮不引入英文 PDF 排版。

## 代码入口

| 位置 | 职责 |
|---|---|
| `client/src/i18n/index.ts` | Vue 响应式语言、初始化、本机记忆、`t()` 和错误提示 |
| `client/src/i18n/messages.ts` | 中文界面文案对应的英文词表 |
| `client/src/i18n/page.ts` | 页面显示与语言变化时刷新原生导航和 TabBar；防止后台页面覆盖当前标题 |
| `client/src/i18n/ui.ts` | 原生提示、弹窗和选项菜单的翻译；可编辑弹窗保留用户内容 |
| `client/src/pages/profile/index.vue` | 语言选择入口 |
| `client/src/features/ai/api.ts` | 每次问答附加当前 `language` |
| `server/src/modules/ai/schemas.py`、`service.py` | 语言枚举校验及可信系统提示词 |

复用 Vue 响应式能力，没有引入新的国际化依赖。新增界面文案使用 `t('中文文案')`，同时补充英文词表；带变量文案使用 `t('第 {n} 题', { n })`。不要把题目、用户输入或公告正文传给 `t()`。语言切换不触发重新导航、重新登录、清空 store 或重建数据库。

## AI 接口与部署

`POST /api/v1/ai/chat` 新增可选 `language: "zh" | "en"`，省略时默认为 `zh`，旧客户端继续兼容。后端将该可信枚举加入系统提示词；英语界面默认用英语讲解中文题目，保留必要中文材料。用户明确要求其他语言时优先按用户要求回答。模型仍为 `qwen3.8-27b`。

本次上线需一起更新前端和后端。仅更新小程序而服务器仍运行旧代码时，界面可以切换，但 AI 默认回答语言不会按本次规则生效。双语功能不改数据库结构；1.5.2 公告通过新增数据迁移 `0009_release_1_5_2` 写入并设为可展示。无需清库、重新导入题库、增加环境变量或安装依赖。见 [1.5.2 公告与发布说明](release-1.5.2.md)。
