# 1.5.3 撤销AI功能

更新日期：2026-10-30。本地代码与构建已完成，尚未部署服务器、执行正式数据库迁移或发布小程序。

## 本次改动

- 删除前端 AI 页面、页面路由、API 调用封装、无用类型与专属图标；移除对应测试和 `test:ai` 命令。
- 底部原生导航改为“首页、刷题、我的”，中英标签和索引一起调整，英文为 Home、Practice、Me。
- 移除收藏、错题详情的“发给 AI”入口、预填逻辑，以及朋友圈预览中的 AI 功能介绍和相关双语文案。
- 后端不再挂载 `/api/v1/ai` 路由，原 `/api/v1/ai/chat` 返回404，OpenAPI也不再暴露该模块。`server/src/modules/ai` 的实现、模型配置和后端单元测试保留，供以后恢复使用；没有修改私有密钥。
- manifest、package、lock及后端版本统一为1.5.3，versionCode为153；“关于”和反馈上报版本读取新版本。
- 不修改登录流程、头像昵称处理或管理员界面。这些仍处于讨论阶段。
- 不删除用户学习记录、旧公告或本机历史聊天缓存。

## 公告与部署

公告由新增数据迁移 `0010_release_1_5_3` 写入现有 `content_items`，依赖 `0009_release_1_5_2`。不改变表结构，不清库、不重新导入题库。

新记录版本1.5.3，标题“1.5.3 更新公告”，摘要和正文均为“撤销AI功能”；启用状态为1，发布时间为实际执行迁移的UTC时间。已有同版本通知则跳过，不覆盖人工编辑或重新启用撤下的公告。回退此数据迁移保留公告历史。

正式发布时按现有流程备份，在更新后的服务器 `server` 目录使用既有Python环境执行：

```text
python -m alembic current
python -m alembic upgrade head
```

然后重启新版后端，并上传1.5.3小程序。只上传前端不会创建公告；只更新前端也不会关闭旧后端AI接口。前后端均需更新；旧版小程序中的AI请求在新版服务上会返回404。

上次正式环境记录为2026-10-26的1.5.2/0009，本次没有登录服务器复查或修改，不能把本地1.5.3构建描述成已经上线。
